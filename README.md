# multi-cloud-launchpad
A modular Terraform starter kit for bootstrapping cloud infrastructure across multiple providers. Includes reusable modules, environment blueprints, and a unified workflow to spin up cloud environments with ease.

## Minimum supported versions

- **Terraform**: >= 1.5.0
- **AWS provider**: >= 5.0
- **DigitalOcean provider**: >= 2.0

These are conservative minimums; newer versions should generally work, but haven’t all been explicitly tested yet.
